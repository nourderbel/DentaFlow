# DentaClinic

Application web de gestion d'un cabinet dentaire, construite avec Next.js,
React, TypeScript et MariaDB.

## Démarrage rapide

1. Installer les dépendances : `npm install`
2. Configurer `.env.local` avec `DATABASE_URL` et `JWT_SECRET`.
3. Lancer le serveur : `npm run dev`
4. Ouvrir `http://localhost:3000`

Sous Windows PowerShell, les commandes npm peuvent être lancées avec
`npm.cmd`.

## Documentation développeur

Consulter le [guide développeur](./PROJECT_GUIDE.md) pour l'architecture, les
modules, les API, la base de données, les règles de sécurité, le stockage des
